# Test Data Storage

## Purpose
Runtime storage for synthetic test applicant data used in development, testing, and evaluation. Contains cross-document-consistent profiles for validating the application workflow.

## Ownership
- Primary: Development Team
- Review Required: No (generated data)

## Local Contracts

### Directory Structure
- `test_applicants/` - Individual applicant profile directories
- Each profile directory contains:
  - `profile.json` - Structured applicant data and expected decision
  - `emirates_id_front.png` / `emirates_id_back.png` - Emirates ID card images
  - `bank_statement.pdf` - Bank statement PDF
  - `credit_report.pdf` - AECB-format credit report
  - `application_form.png` - Handwritten application form image

### Test Profiles
Three representative applicant scenarios:
1. `divorced_employed_good_credit` → Expected: approved
2. `abandoned_unemployed_poor_credit` → Expected: manual_review
3. `unknown_parentage_self_employed_borderline` → Expected: soft_decline

### Data Generation
Generated by `scripts/generate_test_data.py` using the `src/data_generation/` module. Do not manually edit generated files.

## Work Guidance

### Generating Test Data
```bash
.\.venv\Scripts\python.exe scripts/generate_test_data.py
```

### Adding a New Test Profile
1. Add profile definition to `scripts/generate_test_data.py`
2. Run generator to create documents
3. Verify cross-document consistency

## Verification
- Cross-document identity consistency validated by generator
- Documents follow schema specs in `docs/superpowers/specs/`
