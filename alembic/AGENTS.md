# Database Migrations

## Purpose
SQLAlchemy Alembic migrations for PostgreSQL schema evolution. Tracks changes to applicant, document, application, and extraction tables defined in the document processing schema specification.

## Ownership
- Primary: Development Team
- Review Required: Migration changes require review

## Local Contracts

### Migration Standards
- Use `alembic revision --autogenerate` for schema changes
- Review autogenerated migrations before applying
- Never modify a migration after it's been applied to production
- Use descriptive migration messages: `alembic revision -m "add_extraction_confidence_scores"`
- Test migrations on local database before committing

### Schema Design Rules
- Follow PostgreSQL conventions from `docs/superpowers/specs/2026-07-25-document-processing-schema-design.md`
- snake_case naming
- Plural table names
- Singular column names
- TEXT over VARCHAR
- TIMESTAMPTZ for timestamps
- UUIDv7 for primary keys

### Migration Workflow
1. Modify SQLAlchemy models in `src/infrastructure/db/models/`
2. Generate migration: `alembic revision --autogenerate -m "description"`
3. Review generated migration in `alembic/versions/`
4. Test migration: `alembic upgrade head`
5. Commit migration file

### Existing Migrations

- `20260726001_add_state_snapshot.py` — Adds state_snapshot JSONB column to applications table for LangGraph checkpointing

## Work Guidance

### Creating a Migration
```bash
# Generate migration from model changes
alembic revision --autogenerate -m "add_new_field_to_applicant"

# Apply migration
alembic upgrade head

# Rollback one migration
alembic downgrade -1

# Check current version
alembic current

# View migration history
alembic history
```

### Best Practices
- Keep migrations small and focused
- One logical change per migration
- Include both upgrade and downgrade paths
- Test migrations with real data volumes
- Document breaking changes in migration message

## Verification
- Migrations tested on CI with fresh database
- No data loss on upgrade/downgrade cycle
